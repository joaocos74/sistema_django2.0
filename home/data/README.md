# Reflexões de A arte de viver

Catálogo extraído do PDF fornecido pelo usuário: *A arte de viver*, de Epicteto, na interpretação de Sharon Lebell, tradução de Maria Luiza Newlands da Silveira, Sextante, 2006.

São 92 blocos com título, das páginas 18–68 e 72–92 do PDF (páginas impressas 14–64 e 68–88). Foram excluídos capas, introduções e anúncios de outros livros.

O texto de cada bloco foi preservado integralmente, juntando linhas e continuações de página, mantendo os parágrafos e os hífens das palavras. Cada entrada registra as páginas do PDF e do livro para conferência. Não são resumos nem frases geradas.

As aspas que o mapa de caracteres do PDF extrai como barras foram normalizadas após conferência visual com a página original.

O catálogo é lido no servidor. A rota autenticada entrega uma reflexão por clique e evita repetir a última exibida.
