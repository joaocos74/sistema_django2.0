# Sistema de Vigilância Sanitária

Aplicação web para organizar o trabalho da Vigilância Sanitária, com cadastro de estabelecimentos e responsáveis, planejamento e acompanhamento de inspeções, agenda dos fiscais, denúncias, registros da REDESIM e gestão de documentos.

O sistema também permite emitir termos e notificações, consultar históricos e gerar estatísticas e relatórios consolidados.
